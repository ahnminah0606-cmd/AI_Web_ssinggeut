# 씽긋 — 내 생각이 자라는 시간

13~16세 청소년이 영상을 보고, 씽씽과 질문을 만들고, 근거를 찾아 자신의 생각을 정리하는 웹앱입니다.

## 들어 있는 기능

- ChatGPT 계정 로그인 → 닉네임 가입, 계정별 기록 저장
- 실제 OpenAI Responses API를 사용하는 비공개 씽씽 대화
- 질문 / 의견 / 근거 / 다음 질문 기록, 준비 완료 표시
- 선생님 인증 신청과 관리자 승인, 인증된 선생님의 그룹 생성
- 코드로 그룹 참여, 사이트가 제공하는 목록에서 수업 주제 선택, 토론 날짜 설정
- 활동 출석과 씽씽 성장, 최대 3:3 토론 배정과 배심원 배정
- 기존 참여 횟수가 적은 학생부터 토론자로 배정
- 선생님에게는 준비 상태만 표시하고 대화와 개인 노트는 공개하지 않음

## 기술 구성

React 19 · TypeScript · Vinext · Cloudflare Workers · D1(SQLite) · Drizzle

이 프로젝트의 로그인은 **Sites의 ChatGPT 로그인**에 연결되어 있습니다. 일반 이메일/비밀번호 회원가입은 구현하지 않았습니다. 다른 호스팅으로 옮기려면 인증 처리를 해당 환경에 맞게 교체해야 합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
cp .env.example .env
npm run build
npm run db:local
npm run dev
```

`.env`에서 다음 값을 설정합니다. 키는 소스 코드나 채팅에 넣지 않습니다.

```dotenv
OPENAI_API_KEY=본인의_API_키
OPENAI_MODEL=gpt-4.1-mini
SITE_ADMIN_EMAIL=관리자로_쓸_계정_이메일
```

개발 서버가 출력하는 주소(보통 http://localhost:5173)로 접속하세요. 로컬 개발 로그인은 테스트 계정이며 실제 사용자 인증이 아닙니다. 로컬 개발 서버를 인터넷에 공개하지 마세요. 배포 환경에서는 Sites가 인증한 사용자 정보를 사용합니다.

D1 데이터는 `.wrangler/`에 저장됩니다. `db:local`은 마이그레이션 적용 이력을 기록하므로 다시 실행할 수 있습니다. 개발 로그인 계정을 관리자로 테스트하려면 `.env`의 관리자 이메일을 개발 서버가 표시하는 테스트 계정 이메일로 설정하세요.

API 키가 없거나 연결에 실패하면 오류를 표시하며 실제 AI 응답을 흉내 내지 않습니다. API 사용 비용은 해당 OpenAI 계정에 청구됩니다.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `app/ssinggeut.tsx` | 홈, 그룹, 대화, 개인 기록, 인증 신청 화면 |
| `app/globals.css` | 베이비 블루 UI와 반응형 디자인 |
| `app/api/app/route.ts` | 가입·그룹·대화·기록 API |

| `drizzle/` | 배포/로컬 DB 마이그레이션 |

| `app/chatgpt-auth.ts` | Sites 로그인 사용자 확인 |

## API와 권한

`GET /api/app`: 내 프로필·그룹·기록 목록. `action=session`, `action=group`, `action=requests`로 세부 정보를 조회합니다.

`POST /api/app`의 `action`:

- `signup`, `teacher-request`, `review-teacher`
- `group-create`, `group-join`, `topic-create`, `topic-help`
- `session-create`, `chat`, `save`, `allocate`

서버가 사용자 소유권과 그룹 권한을 검사합니다. 학생이 요청 본문을 바꿔 선생님이나 관리자가 될 수 없습니다. AI는 하루 사용자당 최대 60회 요청할 수 있습니다. 대화 내용은 답변 생성을 위해 OpenAI API로 전달되며 `store:false`를 사용합니다. 이는 서비스 DB에서 대화를 저장하지 않는다는 뜻은 아닙니다.

## 운영 설정

Sites 배포 환경에는 `.env`가 자동 업로드되지 않습니다. 사이트의 서버 환경 변수에 `OPENAI_API_KEY`를 비밀값으로 등록하고 `OPENAI_MODEL`, `SITE_ADMIN_EMAIL`을 설정한 뒤 배포합니다. 새 사이트의 접근 권한은 기본 소유자 전용입니다. 실제 학생 초대 전에 사이트 접근 대상을 별도로 설정해야 합니다.

관리자 로그인 → 내 계정의 인증 검토에서 선생님 신청을 승인합니다. 배지는 수동 검토 결과이며 기관 재직 사실을 자동 확인하지 않습니다.

## 현재 범위

씽씽은 실시간 웹 검색을 하지 않습니다. 제공한 수업 자료와 학생이 입력한 내용을 바탕으로 질문과 검색어를 제안합니다. 영상은 포함된 역사 영상 1편이며 새 영상 자동 생성은 없습니다. 별도 알림 발송, 계정 삭제·복구, 학교별 외부 인증은 후속 구현 항목입니다.

## 소스 보관

ZIP에는 소스, 잠금 파일, DB 설계/마이그레이션, 영상과 이미지가 포함되어 있습니다. API 키, 로컬 사용자 데이터, `node_modules`, 빌드 결과는 제외했습니다. 원본 프로젝트의 `.env`는 안전하게 별도로 보관하세요.

학생은 새 탐구를 직접 만들 수 없습니다. 선생님이 제공 목록에서 주제를 선택하면 그룹의 배정 주제로 탐구를 시작합니다. 제공 콘텐츠는 `lib/topic-catalog.ts`에서 관리합니다. 현재 역사 영상과 토론 주제 1개를 제공합니다.

## 디자인 자산과 선생님 화면

상단은 로고 심볼만 사용합니다. 제목은 Jua, 본문은 Gowun Dodum이며 폰트와 OFL 라이선스를 `public/fonts/`에 포함했습니다.

관리자 이메일에 해당하는 본인 계정은 선생님 기능을 바로 사용할 수 있습니다. 상단의 학생 화면 보기 / 선생님 화면 보기 버튼은 관리자에게만 표시됩니다. 일반 학생은 기존 인증 승인 없이 그룹을 생성할 수 없습니다.

`public/assets/ssingssing-blink.png`는 내장 imagegen으로 제작한 2프레임 자산입니다. 프롬프트: 기존 강아지 형태 유지, 몸 안쪽 불투명 흰색, 외부 투명, 왼쪽 눈 뜸 / 오른쪽 눈 감음, 동일 위치와 크기. CSS에서 약 4.8초마다 짧게 깜빡이며 동작 줄이기 설정을 존중합니다.

폰트 원본: https://github.com/google/fonts/tree/main/ofl/jua 및 https://github.com/yangheeryu/Gowun-Dodum

## 선생님 대시보드

선생님 홈은 그룹별 참여율·준비 완료 인원, 회차 선택, 토론 주제 목록, 찬성측·반대측·배심원 배정 명단을 제공합니다. 키우기 UI는 학생 홈에만 표시합니다. `GET /api/app?action=teacher-summary`는 본인이 소유한 그룹만 반환하며 학생 대화나 노트 본문은 포함하지 않습니다.

참여율 = 선택한 회차에서 대화 전송 또는 질문·의견·근거를 기록한 학생 / 그룹 학생. 최신 탐구 상태를 사용합니다. 자동 배정은 최대 3:3, 이전 토론 참여가 적은 학생 우선의 규칙 기반 알고리즘이며 언어 모델의 임의 판단으로 학생을 평가하지 않습니다.

## 체험 로그인

상단 체험 로그인에서 `학생01`~`학생06`, `선생님`을 선택하거나 입력합니다. 비밀번호는 없고 실제 회원가입은 아닙니다. 같은 브라우저 localStorage에 체험반·주제·개인 기록·배정 결과를 저장하며 현재 계정은 탭의 sessionStorage에 보관합니다. 실제 서버 API나 OpenAI를 호출하지 않고 체험 AI는 예시 응답으로 표시합니다. 체험 종료를 누르면 기존 실제 로그인으로 돌아갑니다. 학생별로 내 그룹 → 체험 토론반 → 씽씽과 준비하기 → 생각 기록과 입장 선택 → 준비 마치기를 진행한 뒤 선생님으로 전환하면 참여율과 배정 결과를 테스트할 수 있습니다.
